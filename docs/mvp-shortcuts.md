# MVP shortcuts register

Shortcuts taken to ship the MVP. Each one must be resolved before building past the MVP; the "Fix before" column says what should trigger the fix.

## Rules

- **Code markers.** Every shortcut gets a comment at the exact spot it lives:

  ```ts
  // MVP-SHORTCUT(MVP-03): <one line describing the shortcut>
  ```

- **Audit.** `rg "MVP-SHORTCUT"` must match this register one-to-one: every open ID below has at least one marker, and every marker points to an ID below. New shortcuts get a new ID here in the same change that adds the marker.
- **Issues.** After the MVP ships, each ID gets one GitHub issue labelled `mvp-debt`, linked from this table.
- The OverwatchRoulette repo keeps the same file under the same name; MVP-11 and MVP-12 live there.
